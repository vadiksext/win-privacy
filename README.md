# win-privacy

Настройки конфиденциальности Windows 11, Edge и Office штатными политиками (значения реестра
в ветках `Policies`). Службы не останавливаются, hosts и сетевой экран не трогаются, сторонних
программ нет. Всё, что скрипт меняет, перечислено в `win-privacy.json` — его можно прочитать
и показать заказчику.

## Запуск

| Что | Двойной щелчок | Из командной строки |
|---|---|---|
| Проверить, ничего не меняя | `check.cmd` | `win-privacy.ps1` |
| Применить | `apply.cmd` | `win-privacy.ps1 -Apply` |
| Откатить последнее применение | `undo.cmd` | `win-privacy.ps1 -Undo` |

- Проверка работает без прав администратора. Применение и откат сами запрашивают UAC
  и продолжаются в новом окне.
- Исключить группы: `apply.cmd -Skip OneDrive,Location`. Имена групп — в квадратных скобках
  в выводе проверки.
- После применения нужна перезагрузка.

## Что куда пишется

- `logs\` — журнал каждого запуска.
- `backup\` — прежние значения изменённых параметров. Откат берёт самый свежий файл
  и помечает его использованным (`.undone`), следующий откат возьмёт предыдущий.

## Ограничения

- Параметры пользователя (`HKCU`: Office, Copilot, подсказки поиска) применяются только к тому,
  кто запустил скрипт. Для второго пользователя запустить под ним.
- Windows 11 Pro не умеет выключать диагностические данные полностью: остаются «обязательные».
- При включённой «Защите от подделки» Защитник может игнорировать часть политик — проверка
  показывает, что он использует на деле.
- Политики Office официально рассчитаны на корпоративные выпуски. Действуют ли они на розничный
  Office, проверяется в самом Office: «Файл» → «Учётная запись» → «Конфиденциальность учётной
  записи».
- Мини-приложения (Widgets) скрипт не отключает: в раздел их политики Windows не даёт писать
  даже администратору (по всей видимости, это делает драйвер защиты пользовательского выбора
  UCPD). Отключать вручную: `gpedit.msc` → «Конфигурация компьютера» → «Административные
  шаблоны» → «Компоненты Windows» → «Мини-приложения» → «Разрешить мини-приложения» →
  «Отключено». Либо удалить приложение «Windows Web Experience Pack».
- Скрипт — ASCII, русские тексты лежат в `win-privacy.json` (UTF-8): Windows PowerShell 5.1
  читает скрипты в ANSI. Переносить нужно всю папку.
